## 项目简介
本项目是一套灵巧手抓取系统的模块化架构。系统由四个主要模块组成：理解、视觉、规划和控制。每个模块都有其独立的子模块，架构设计旨在简化代码迁移、统一编码风格，并便于未来模块的扩展。以下是每个模块及其功能的详细说明。

## 1. 理解模块
**输入:** 语音  
**输出:** 抓取目标名称

### 1.1 语音转文字子模块
此子模块将语音输入转换为文本。支持多个模型或API（例如讯飞），每种方法都有独立的文件便于管理。

### 1.2 文字理解子模块
此子模块处理文本输入以提取抓取目标。  
**示例输入:** "帮我拿一个黄色的卷尺"  
**示例输出:** "黄色的卷尺"

## 2. 视觉模块
**输入:** 图像 + 抓取目标名称  
**输出:** 2D/3D（质心/朝向）或重建的3D物体表面

### 2.1 条件分割子模块
此子模块使用现有的离线模型，根据抓取目标名称对输入图像进行分割，获得目标物体的掩码（mask）。

### 2.2 细颗粒感知子模块
基于掩码，此子模块获取目标物体的质心和朝向。  
- **2D优化:** 返回图像中的质心和朝向。  
- **3D优化:** 结合摄像头的深度信息，重建物体表面，返回3D情况下的质心、朝向以及表面信息。

## 3. 规划模块
**输入:** 抓取目标的视觉感知结果 + 放置点的视觉感知结果（留坑）  
**输出:** 机械臂的一系列关节位置或tpose，以及灵巧手的抓取/释放方式和时机

### 3.1 灵巧手规划子模块
当前情况下，此子模块基于视觉感知结果，在两个抓取姿态中选择一个。未来会替换为Allergo灵巧手的生成抓取策略。

### 3.2 机械臂规划子模块
此子模块规划从当前位置到抓取位置再到放置位置的轨迹。它检查是否存在解，并在无解的情况下提供近似处理方法。

## 4. 控制模块
**输入:** 一系列位置或tpose  
**输出:** 现实世界中的运动

### 4.1 灵巧手动作控制
在实现生成的抓取策略之前，先使用几套预定义的抓取模式。

### 4.2 机械臂动作控制
此子模块包括硬碰撞规避，通过将机械臂和附近的障碍物写入代码，确保系统不会损坏机械臂或自身。（尚不确定是否可以添加自碰撞检测功能）

## 遇到的坑
1、运行robot.movel(pose_list[0], acc=0.05, vel=0.05, wait=true),urx.urrobot.RobotException: Robot stopped

在/anaconda3/envs/your_env/lib/python3.*/site-packages/urx/ursecmon.py这个文件，把
```
if self._dict["RobotModeData"]["robotMode"] == rmode\
```
改为
```
if self._dict["RobotModeData"]["robotMode"] == 7 \
```
问题解决。

2、module ‘collections‘ has no attribute ‘Iterable‘报错
在/anaconda3/envs/your_env/lib/python3.*/site-packages/math3d/utils.py 的
```
import collections
```
后面加上
```
collections.Iterable = collections.abc.Iterable
```
